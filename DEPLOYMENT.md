# ShipLogix - Инструкция по развертыванию

## 🚀 Быстрый старт (Локальное развертывание)

### Предварительные требования
- **Node.js** версии 18 или выше ([скачать здесь](https://nodejs.org/))
- **npm** (устанавливается вместе с Node.js)

### Шаг 1: Экспорт проекта из Dazl

1. Откройте **Dev Tools** (иконка в правом верхнем углу)
2. Перейдите на вкладку **Code**
3. Нажмите кнопку **Export** в правом верхнем углу
4. Сохраните ZIP-архив на ваш компьютер
5. Распакуйте архив в удобную папку

### Шаг 2: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Это установит все необходимые библиотеки (React, React Router, UI компоненты и т.д.)

### Шаг 3: Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:5173**

### Шаг 4: Сборка для продакшена

```bash
npm run build
```

Оптимизированная версия будет создана в папке `build/`

## 🌐 Развертывание в интернете

### Вариант 1: Vercel (Рекомендуется) ⭐

**Почему Vercel:**
- Бесплатный хостинг
- Автоматическая настройка для React Router
- SSL сертификат
- CDN по всему миру
- Мгновенное развертывание

**Инструкция:**

1. Зарегистрируйтесь на [vercel.com](https://vercel.com)
2. Установите Vercel CLI (опционально):
   ```bash
   npm install -g vercel
   ```
3. В папке проекта выполните:
   ```bash
   vercel
   ```
4. Следуйте инструкциям в терминале
5. Получите ссылку вида `https://shiplogix.vercel.app`

**Или через веб-интерфейс:**
1. Загрузите проект на GitHub
2. Зайдите на [vercel.com](https://vercel.com)
3. Нажмите "Import Project"
4. Выберите ваш репозиторий
5. Vercel автоматически настроит все параметры
6. Нажмите "Deploy"

---

### Вариант 2: Netlify

1. Выполните сборку:
   ```bash
   npm run build
   ```
2. Зайдите на [netlify.com](https://netlify.com)
3. Перетащите папку `build/client` в окно браузера
4. Или подключите GitHub репозиторий с настройками:
   - **Build command:** `npm run build`
   - **Publish directory:** `build/client`

---

### Вариант 3: Cloudflare Pages

1. Зарегистрируйтесь на [pages.cloudflare.com](https://pages.cloudflare.com)
2. Подключите GitHub репозиторий
3. Настройки сборки:
   - **Build command:** `npm run build`
   - **Build output directory:** `build/client`
4. Нажмите "Save and Deploy"

## 🐛 Решение проблем

### Ошибка при установке зависимостей
```bash
# Очистите кэш npm
npm cache clean --force

# Удалите node_modules и переустановите
rm -rf node_modules package-lock.json
npm install
```

### Порт 5173 уже занят
```bash
# Измените порт в vite.config.ts или закройте другое приложение
```

### Приложение не загружается после деплоя
- Проверьте, что указана правильная папка сборки (`build/client`)
- Убедитесь, что настроен SPA fallback (для Netlify создайте `_redirects`)
